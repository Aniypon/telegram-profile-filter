```json

  "performance": {
    "enable_performance_monitoring": true,
    "enable_caching": true,
    "batch_size": 5
  }
}
```

## 🚨 Предупреждения и пороги

Система автоматически предупредит вас, если:
- Обработка формы > 1 сек
- API вызов > 2 сек  
- Загрузка медиа > 5 сек
- Валидация > 0.1 сек
- Файловая операция > 0.5 сек

## 🔍 Профилирование

Для детального профилирования добавьте:
```python
import cProfile
import pstats

# В main.py
profiler = cProfile.Profile()
profiler.enable()

# Ваш код

profiler.disable()
stats = pstats.Stats(profiler)
stats.sort_stats('cumulative').print_stats(20)
```
